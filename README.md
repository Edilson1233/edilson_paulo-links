## 🚀 Funcionalidades

- **Fundo animado** — Rede de partículas em `<canvas>` com linhas de conexão dinâmicas
- **Contador de visitas** — Persiste via `localStorage`; anima o número com easing ao carregar
- **Copiar Link** — Usa a Clipboard API com fallback para browsers antigos; exibe toast de confirmação
- **Efeito Typewriter** — Título rotativo com animação de digitação e cursor piscante
- **Cursor personalizado** — Anel com interpolação linear (lerp) em modo desktop
- **Glassmorphism** — Card principal com `backdrop-filter: blur`
- **Design responsivo** — Mobile-first; funciona de 320 px até desktop

## ♿ Acessibilidade

- Atributos `aria-label` em todos os links e botões
- `aria-live` no contador de visitas e typewriter
- Suporte a `prefers-reduced-motion` (desativa animações)
- Navegação por teclado com `:focus-visible`
- Cursor nativo restaurado em dispositivos touch
